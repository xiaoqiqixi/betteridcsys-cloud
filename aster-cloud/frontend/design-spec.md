# Aster 云管理

## 方向与取舍

这是一套管理服务器、节点与操作任务的工作界面，不是销售首页。参考 Apple HIG 的内容优先、分层、明确反馈、可及性原则，不复制财务界面、已有截图或第三方产品。

放弃常见“统计卡仪表盘”：首屏直接是可搜索的实例清单。使用一条52px的一体command rail，不再叠加侧栏和第二条topbar；1025px起六个入口横向呈现，1024px及以下转为有焦点约束的导航抽屉；实例名称与当前状态优先，CPU/内存/磁盘作为同一行的规格。实例详情在完整页面呈现，危险操作只在确认对话框中完成。迁移使用四阶段向导，分别说明准备、安全传输、导入、激活，绝不因上一请求已受理而自动执行下一阶段。

## 导航的响应式边界（本轮 Gemini 视图集成）

- 采用 Gemini 独立生成的 `WorkbenchHeader` 纯视图结构：一条52px sticky command rail，品牌、六个入口和账户/语言/退出同层；移除旧可见侧栏、重复topbar及正文左侧占位。色彩映射现有浅/深语义tokens，不另造第二套主题。
- `NavLinks` 保管原来的权限过滤并通过Vue scoped slot给rail提供同一份入口。Header只消费props/发出展示事件，不创建session、API、资源、计时器或mutation。主页面的route permission gate仍是深链的最终视图门禁；不能用“默认高亮第一个可用项”掩饰无权路由。
- 导航为真实RouterLink/anchor，保留URL、modifier新标签行为和键盘语义；按完整segment边界匹配，网络各子路由归一到“网络与 IP”，不把`/nodes-unrelated`误当节点。紧凑上下文可由准确的`currentPageLabel`提供，未匹配时不虚构当前入口。
- 桌面导航区域独立横向滚动，保留44px触达区域、焦点安全边距与完整点击区域；键盘聚焦只调整导航自身scrollLeft，不滚动业务正文。宽度足够时六项自然完整呈现，不为了测试刻意制造溢出。短屏rail保持52px；紧凑短屏抽屉的body独立纵向滚动，品牌/账户不参与业务正文滚动。
- 1024px及以下仅保留紧凑上下文、utilities与带`aria-expanded`/`aria-haspopup=dialog`的菜单。跨到桌面通过原`UiOverlay`收束history、滚动锁和inert，并将焦点移到可见main；从桌面导航切入紧凑布局时将焦点移到菜单按钮。CSS先blur的情况仍保留导航焦点记忆，不抢走业务输入框焦点。
- 抽屉路由失败保留原导航；成功导航、Escape、背景和浏览器返回仍按原契约关闭。会话busy或pendingAuth禁重复退出，不改会话刷新/epoch/未知结果保留。所有媒体/文档监听卸载时清理，无300ms演示计时器或假数据。
- 门禁覆盖320/390/768/1024/1025/1440、真实长页顶/中/底、1440×360与1025×360、缩放等效CSS视口720×450和512×384。CI文件/截图中的`sidebar`保留为legacy标识，记录实际`command-rail-v1`，不是仍有侧栏或已沿用旧证据。jsdom只能证明生命周期与导航契约，不替代Firefox真实几何或真实200%浏览器缩放。

## 视觉契约

- 瓷白画布 `#f5f6f8`，白色内容面 `#ffffff`，石墨文字 `#1d2533`，次级文字 `#536174`，分隔线 `#dce1e8`，蓝色操作 `#175cd3`。深色使用独立语义色，不反转整页。
- 系统字体栈，中文 PingFang SC / Microsoft YaHei；正文15px、辅助13px、页标题28px。正常字重400/500/600，不用细灰字制造高级感。
- 4/8/12/16/24/32间距；内容最大1440px。44px最小交互高度。控件10px、内容组16px、浮层20px，不让所有内容都变成等尺寸卡片。
- 边界用于表达分组；阴影只用于浮层。不做炫光、营销渐变、装饰数字或无意义统计。
- 动效只回应交互：120–180ms透明度与小幅位移；尊重reduced-motion。骨架只在加载阶段，失败绝不显示空列表。

## 组件与状态所有权

- `api/client.ts`：同源真实HTTP、cookie、CSRF、严格JSON、安全错误分类，无演示回退、无自动重试。
- `useSession`：身份与epoch、权限、登出后清空资源；迟到响应不得恢复旧会话。
- `useMutation`：稳定32位小写hex意图key；发送后结果未知锁定，保留key，不能通过关闭重开自动重发。只把202叫“已受理”，不叫“已完成”。
- `UiOverlay`：独立浮层生命周期、焦点锁定/恢复、Escape/背景/浏览器返回；忙碌时不关闭。
- `UiSelect`：自定义listbox，方向键/Home/End/Enter/Escape和类型搜索，无原生select。
- `UiButton / StateBlock / StatusBadge / ToastStack`：统一忙碌、空、错、状态反馈，不依赖颜色传达意义。
- 页面只消费明确DTO，测试fixtures仅在tests下，生产入口绝不导入。

## 安全与验收边界

真实接口默认 `/console/v1`；不提供用户可切换的数据来源。权限以服务端返回为准，未知权限禁止危险动作。危险操作必须逐字输入实例ID，最终由后端确认。网络未知时保留意图并引导查看任务，不能假成功/自动再次派发。CSRF和会话只留内存，密码不持久化。

本地执行typecheck、Vitest、format、build；实际320/375/768/1440浏览器与真实后端由root另行验收，不能以单元测试替代视觉验收。

## VPC、路由与 NAT 管理

- 入口 `/networks/overlays`，与节点网络、IP 地址池、地址分配放在同一层导航；集群选择保存在 URL，浏览器返回恢复上下文。主要工作区是 VPC、当前配置和变更记录，不加装饰统计卡。
- VPC 可以采用预批准映射 ID，也可以新建 ID；后者明确标为“尚未映射节点”，不会绕过节点映射批准。VPC 元数据保存不冒充网络已接通。
- `OverlaySelectionEditor` 管理完整成员与网关选择；`OverlayNATEditor` 管理批准出口、SNAT 和端口映射。只展示安全候选投影，不提供任意宿主命令、设备路径或裸 JSON 编辑器。NAT 引用仍存在时不能悄悄移除网关或目标成员。
- `OverlayEpochDialog` 管理计划/恢复确认；恢复固定原 SHA-256、新操作 ID，可保留原配置或明确提交完整替换。根配置变化时禁普通变更，未批准迁移时禁恢复。故障成员保留身份；仅明确删除的实例可由操作员移出成员表。
- `OverlayEpochPage` 展示全部节点的准备、应用、放行三阶段、完整回执代码和原版本依据；继续执行、只读核对、恢复都是独立显式动作。节点确认不等于已完成真实流量验收。
- `useOverlayMutation` 在发送前持久化非秘密的完整意图，并按账号/集群/原版本锁定。未知响应时关闭、重开、更改草稿、刷新不产生另一个 POST；只读核对须匹配完整原意图，迟到的旧页面/旧会话响应不解锁。存储不可用或损坏时不发送。
- 新增组件仍使用现有语义色和自定义 UiSelect/UiOverlay。手机端成员、端口规则、节点阶段改为单列；桌面保留宽表格式分组。表单忙碌状态、焦点、Escape、背景关闭、浏览器返回复用已验证的浮层契约。
- 通知只补充页面与任务中的持久状态，不承担最终成功判定。信息提示最多一条、五秒自动关闭，鼠标停留或键盘阅读时暂停；错误去重且有界，不按计时消失。弹窗打开时后台通知隐藏并排除交互，层级低于遮罩；语言或身份变化清除旧文字，离场清理计时器，不能堆叠遮挡手机确认按钮。

## 公网 IPv4 出口

- 保留原 NAT 编辑器的状态边界与视觉语言：石墨正文、瓷白/深色语义面、蓝色选中、细边界；不另加全局开关或装饰统计。SNAT 与出口范围在桌面成对展示，窄屏改为单列；出口 IPv4 和节点身份始终就近显示。
- 出口范围使用现有 `UiSelect`，明确区分“仅指定网段”和“公网 IPv4”。只有节点允许公网且出口为有效公网单播地址时才能选择公网；未开放时显示原因，不把隐藏或不可点当作完整反馈。关闭 SNAT 同时移除公网选择，独立 DNAT 规则保持不变。
- 指定网段可明确留空，表示没有指定路由，不隐式扩展为默认路由。公网模式独立控制公网访问；私有、保留与管理地址仍受保护，原 DNAT 来源/端口合同不扩大。
- 配置与恢复对话框对公网范围增加显式确认，复用原集群名/变更 ID 确认与忙碌、焦点、关闭保护。复选框保留原生键盘行为，外观由当前设计 token 绘制。选择不冒充生效，受理后仍需查看各节点回执。
- 概览、历史版本详情与原配置恢复均展示出口范围。出口地址只有在完整节点/VPC/网关/配置 ID/SHA-256 对应时才引用当前安全投影；无法核实时不猜测旧版本地址。
- `internet_egress_enabled` 仅在 true 时进入规范化意图，旧省略/false 等价；公网与非公网意图绝不等价。未知 POST 的只读核对仍匹配完整模式，不以丢失新字段的 GET 解除锁定。
- 本轮实际读取 ui-skills-root、interface-design、vue-best-practices 及四项核心参考。UI Skills CLI 离线缓存仍不可用（ENOTCACHED），本轮没有新安装或声称调用 Gemini。

## 公网 IP 库存与分配

- `/networks/public-ips` 是网络第二级导航，集群、池/分配记录及游标保存在URL；不新增装饰统计卡。数量只表示库存，不从租约差集推断空闲。
- `PublicIPsPage` 拥有列表与确认后刷新；`PublicIPDialog` 拥有范围/列表输入、精确VPC/出口选择及typed IP回收确认；`usePublicIPMutation` 独立持久保管完整actor/action/target/request；严格DTO和原操作GET核对在 `api/public-ip.ts`。
- 创建、补充、启停、分配、回收以服务端固定结果为准。丢ACK跨关闭/刷新仍阻断新地址POST，GET须匹配原账号/ID/动作/目标/完整请求及相符结果。保留released历史，显示服务端绑定/待确认/不可回收状态，不把预留叫网络已接通。
- NAT选址仅列精确VPC/owner/node/profile的reserved租约；`public_ipv4`进入新冻结意图及完整比较，缺省不改旧字节。历史显式IP从冻结版本读取，不从当前默认地址猜旧绑定。
- 复用UiSelect/UiOverlay/UiButton、可见错误、44px交互及焦点/dirty关闭契约；新表单novalidate配合自定义错误，不弹系统校验气泡。桌面紧凑分组，≤600px单列，中英浅深主题及实际320/390/1440浏览器另验。
- 实际读取ui-skills-root、interface-design、vue-best-practices与4个核心参考。ui-skills CLI尝试失败（registry ENOTFOUND），采用本地技能，没有宣称新安装或调用Gemini。

## 实例公网地址

- 地址池库存继续共享；NAT 分配、虚拟机直绑和独立浮动 IP 不共用结果 DTO 或操作意图。
- 主信息为地址、使用方式和后端投影的绑定状态，不加统计卡。客户与节点 ID 允许换行，移动端操作纵向排列且保留 44px 触达区域。
- 分配使用已批准网络与地址池交集，客户引用支持已有选择和合法新引用；不在这里创建财务客户。
- 绑定与回收编辑时冻结资源代数。未知结果保留完整原意图，只能 GET 原操作核实，不能因刷新而更换客户、目标或代数重发。
- 浮动 IP 的绑定/跨节点切换须明确确认目标客户与私网地址。地址绑定与公网入站授权分离：新绑定默认拒绝新入站，按目标实例的来源/协议/端口规则处理；不搬运原实例规则，不用确认勾选冒充访问控制。
- 接收成功只表示保存意图。浮动变更链接网络任务，直绑接纳/解绑链接节点任务；后端核实前显示待处理，不能显示已接通。
- 创建直绑实例仅向要求公网资源的规格添加 `public_ip_resource_id` 与用户选择时冻结的 `public_ip_expected_generation`；旧创建请求省略两字段。公网迁移目标由完整的后端兼容性投影决定，不将在线状态当作兼容证明。

- 迁移源退役作为独立第 5 步展示在实例概览：只有后端投影为待退役时可新建任务，须确认实例 ID、迁移 ID 与永久源清理；已受理、未知、受阻或已完成时只链接原操作，不能重复创建；后端确认已拒绝且重新投影为待退役后，允许新的明确确认并保留上次任务链接。202 不代表已清理。

## W07-A 成员分页

- UsersPage保留成员列表与编辑抽屉；useUsersPage仅拥有请求取消、身份代次和成功后提交的游标栈，不接管写表单或角色委派逻辑。
- 上一页/下一页在列表末尾成组，44px触达、窄屏换行，页码及当前页人数通过status通知；不展示未经后端确认的总人数。
- 首次加载沿用骨架；换页期间保留已读行并显示轻量载入态，禁止重复翻页；瞬断保留上次成功页并就近给出重新加载，错误不推进页码。顶部刷新回首页，保存后重读当前页，创建后回首页。403显示无权限而非空列表，401清身份，任何身份/权限变化清页栈并关闭旧抽屉。
- 打开编辑抽屉时禁止翻页/刷新丢失编辑上下文；已有dirty/焦点/Esc/返回契约由UserEditor保留。本轮不改账号写入合同。
- 新页面拒绝旧无next_cursor响应、重复ID、超限人数和矛盾分页标记；具体游标保持opaque，不在前端转换微秒时间。角色按钮可用性不替代后端users.manage和mayManage。
- 本轮读取vue-best-practices及四项核心参考；未调用Gemini。JSDOM行为检查不是实库浏览器或桌面/手机视觉验收，后者仍需同SHA另验。

- 浏览器跨路由返回恢复原页码/滚动移交W15：当前离开后重进成员页重新读取第一页并回顶部，不假称返回体验全部完成。

## 成员变更、冲突与会话撤销（W07-B）

用户是处理值班和账户交接的管理员，任务是准确修改资料/授权、结束已有登录以及核对不明确的更改；
感觉应是可靠的运维台账，不是营销控制台。领域词为成员、授权、会话、版本、回执、变更说明；
色彩沿用机房工作台的瓷白、石墨、钢灰、操作蓝和克制的警示琥珀。
标志结构是连续ledger表单加内嵌原操作反馈。拒绝三种默认：统计卡片填空、全屏红色警报、随手另造一套select/modal。

- Gemini App负责三份视图原创：IdentityEditorFields、IdentityOperationNotice、IdentitySessionRevocation；只交换需求与公开组件/API合同，无源码/旧图/凭据。取回后接现有UiSelect/Button/Overlay及主题token，source哈希见根目录本轮执行记录。用户允许额度不足时自行补接，不把自行集成说成新一轮Gemini设计。
- 表单先加载最新版本，再显示可编辑资料；固定角色权限只读，自身角色/启停/授权锁定。姓名/邮箱/角色分组、密码单向输入、说明必填。Unicode字数与密码字节数分开，不用原生浏览器校验气泡。
- revision冲突保留原稿、禁继续覆盖，只允许明确放弃并重读。结果待核对冻结输入，只核对原ID；404不能解锁。关闭或刷新后在成员页继续看到本人待核对记录，不堆重复成功toast。
- 撤销会话是独立高危行，完整显示成员和ID，不要求重复抄长ID；理由必填，说明包括所有设备且不会停止VM/取消任务。本人撤销后立即离开已认证界面，未知记录待重新登录核对。
- 嵌套确认层只允许最上层焦点、Escape/Back；背景父层inert但保持数据/滚动锁，子层关闭恢复原触发器。身份变化同时关闭两层时不遗留伪历史或恢复后台交互。
- 320/390单列不横滚，桌面保持可扫分组；浅/深对比、长ID、字数提示、busy/reduced-motion和自然中英文同时保持。e566f20已实际通过29项身份浏览器并人工查看全部10图；新截图等待确认层实际入场且只截视口，不以1001组件测试替代视觉完成。此记录不替后续源码或整套产品验收背书。
- 冲突、待核对与阻塞反馈出现时进入当前活动层的视野和焦点；子确认不聚焦inert父层。确认Teleport后的输入边界与警示色必须实际计算可见，不能只查原父层变量。
- 完整刷新只清理无存活层的本应用弹窗history标记，保留路由及待核对意图。浏览器Back仍需关闭最上层；不以清空业务账本解决导航问题。
