# 星屿云资源域

本域描述实际计算资源，与财务销售目录及账务独立。

## 语言

**主控**：统一管理区域、计算节点、资源归属与资源任务的控制系统。
_Avoid_：财务系统、宿主机

**计算节点（被控）**：承载并运行客户虚拟机的宿主机，接受经授权的资源操作。
_Avoid_：客户虚拟机、目录节点、普通业务 Agent

**实例**：占用计算、磁盘及网络资源的客户虚拟机。
_Avoid_：订单、账单、计算节点

**目录节点**：财务系统中用于客户选购的商品分类，不表示实际宿主机。
_Avoid_：计算节点

**资源任务**：一个具有稳定身份与明确目标的资源操作意图，其接纳与执行结果分别确认。
_Avoid_：付款、已开通

**资源预留**：任务被接纳后占用的容量或地址额度，不表示虚拟机已经运行。
_Avoid_：实际使用量、空闲容量

**结果不明**：操作可能已产生作用，但当前无法可靠确认的结果；既不是失败，也不是成功。
_Avoid_：未执行、可重试失败

**监控采样**：某个时刻读取的资源状态与运行统计，不代表持续健康、执行完成或账务结算。
_Avoid_：计费记录、开通回执

**累计计数**：资源自其计数起点以来的总量，可能因重启等原因重置；不是某个账期的已结算用量。
_Avoid_：实时速率、账单流量
